
# YOLOv8 QR Code Detection

## 📦 Installation

### 1. Create Virtual Environment
```bash
python -m venv venv
```

### 2. Use Virtual Environment
```bash
.\venv\Scripts\activate
```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

### 4. Training Model
```bash
python train_yolo.py
```
